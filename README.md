# Edwin Anajemba

Personal site of Edwin Anajemba, software product engineer. I lead the product team at JointEarn and build web platforms and cloud infrastructure, from payments to Web3.

**Live:** https://anajembaedwin.github.io

## What is on the site

- Services, experience and live products I have contributed to
- Products I build (BeezyLabs Store, BeezyApply)
- Selected code on GitHub
- Small browser games
- Contact form, in English, French, Portuguese and Spanish

## Stack

React (Create React App), React Router, react-i18next, deployed to GitHub Pages with `gh-pages`.

## Run it locally

```
npm install
npm start
```

Open http://localhost:3000.

## Build and deploy

```
npm run build
npm run deploy
```

`npm run deploy` publishes the `build` folder to the `gh-pages` branch.

## Where things live

- `src/data/`: site content (experience, live products, projects)
- `src/i18n/`: translations
- `src/pages/`: one file per page
- `public/`: static files and games
